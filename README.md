# Velis Open Source & LGPL Compliance

This repository hosts corresponding source code archives, build scripts, and license notices for open-source libraries dynamically linked by the Velis media player, in compliance with the **GNU Lesser General Public License (LGPL) v2.1**.

## Components
- **VLCKit / libVLC**: Custom dynamic build configured for Apple platforms with TrueHD and MLP audio decoding enabled.

## Releases
Source code archives and build instructions are published under [Releases](https://github.com/unkitd/Velis/releases).
